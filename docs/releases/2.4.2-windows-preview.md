NYXOR 2.4.2 preview brings the Android moon theme and farming engine to Windows 10/11 x64.

### New and improved

- A desktop layout with sidebar navigation, rounded cards, animated dropdowns and Twitch reward artwork.
- Separate Twitch accounts with independent logins, lists, progress and history. Several profiles can farm concurrently; the account selector identifies the current view.
- Hold an account card, or choose Select accounts, to remove several profiles. Cancel, Escape or unticking the last profile leaves selection mode. Removal stops only selected accounts and deletes their saved data.
- Active Drops and claimed rewards show item images returned by Twitch. The inventory has a game filter and keeps the latest 500 rewards.
- Minimize or close hides the app in the tray; a single left-click restores it. Tray controls show the farming status.
- Chrome opens only for an explicit Twitch login and closes after verification. Farming uses the saved session; an expired session pauses that account and asks for reconnection.
- Energy saver and a minimal-resource mode reduce background checks and engine priority.
- Windows startup can open only the app or also start farming for opted-in accounts.
- The window opens maximized within the display work area. Status and Settings controls no longer overlap.
- Game search uses Twitch's public catalog, including World of Tanks.
- Setup requests administrator permission, supports choosing the installation directory and checks installed/orphan processes without confusing setup itself for NYXOR.

### Install

Download **NYXOR-Windows-2.4.2-preview-Setup.exe** under Assets, run it, approve the administrator prompt and select a folder. Python and Node.js are bundled. **Google Chrome is required for Twitch login.** Open Settings → Connect Twitch, add games or channels and start farming.

Existing account data is stored separately from the installation directory. The app itself runs without administrator privileges. This preview installer is unsigned, so Windows may show an unknown-publisher confirmation.

### Validation

79 Python tests and 20 Node tests passed for this packaged version. The frozen backend, native app, account deletion and surviving-account isolation, display sizing, tray restoration and resource mode were checked. Seven installer regression checks and privilege checks passed. Twenty demo screenshots cover seven routes and six viewport sizes.

Real parallel-account farming, live reward claiming, extended sessions and an update of an actual Program Files installation have not been verified. Screenshots use fictional demo data. The release tag points to the commit used to build this Windows installer.
