# Оновлення NYXOR: інтерфейс і спільні кампанії

Це робоча версія вихідного коду з новим інтерфейсом для Termux. Вона ще не опублікована в GitHub як реліз.

## Що змінилося

- Компактна головна панель, темна палітра, фіолетові акценти та м’ятні шкали прогресу.
- Окремі нагороди кожної кампанії на поточному каналі. Хвилини беруться з Twitch, а не додаються локально.
- Кнопки Старт, Стоп і Рестарт завжди внизу головної вкладки.
- Деталі з’єднання й додаткових нагород розгортаються за потреби; налаштування можна прокручувати.
- Українська та англійська мови, адаптація до вузького термінала.

## Як обирається канал

Порядок ігор у твоєму списку збережено. Усередині поточної гри NYXOR обирає онлайн-канал, який підходить найбільшій кількості активних незавершених кампаній. Наприклад, якщо кампанія A дозволяє Streamer1, а кампанія B — Streamer1 і Streamer2, пріоритет отримує Streamer1.

Рахуються кампанії, а не кількість нагород у кожній. Завершені нагороди, майбутні або прострочені кампанії, відсутня прив’язка та невиконані залежності не збільшують пріоритет. За однакового результату діють попередні вподобання стрімерів. Якщо спільний канал офлайн, можна продовжити доступну кампанію на іншому каналі.

## Встановлення на телефоні

1. Зупини майнер кнопкою Стоп і закрий інтерфейс.
2. Збережи резервну копію своєї поточної папки NYXOR.
3. Розпакуй архів `NYXOR-ui-drops.zip`. Скопіюй вміст папки `NYXOR` поверх програмних файлів у своїй папці `~/NYXOR` через доступний тобі файловий менеджер або термінал.
4. Архів не містить `cookies.jar`, `nyxor_settings.json`, журналів чи історії. Залиш свої наявні файли на місці.
5. У Termux виконай:

```sh
cd ~/NYXOR
python -m pip install -r requirements-termux.txt
python nyxor_app.py
```

Якщо команда `nyxor` вже була встановлена, нею також можна запускати оновлений інтерфейс. Звичайний `git pull` поки не завантажить ці зміни: вони ще не опубліковані в репозиторії.

## Перевірка

```sh
python -m unittest discover -s tests -v
```

Перевірено 16 сценаріїв вибору каналів та інтерфейс на 40, 80 і 120 колонок двома мовами. Знімки інтерфейсу використовують вигадані кампанії. Перевірки виконані локально без авторизації Twitch; реальне нарахування дропсів і робота на Android потребують перевірки у твоєму середовищі.
