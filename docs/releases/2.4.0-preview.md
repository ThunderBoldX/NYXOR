NYXOR 2.4.0 preview for Android adds separate Twitch accounts and illustrated reward inventories.

### New and improved

- Separate accounts with independent logins, priority lists, farming progress, history and activity journals. Several accounts can farm concurrently; switching the view keeps other accounts running.
- Hold an account card to select several profiles, then delete or cancel. Removing the last check exits selection mode. Deleting profiles removes their saved login and data.
- Twitch reward images in active Drops and the claimed-reward inventory, with a game filter and a limit of 500 recent rewards.
- Rounded animated dropdowns across the mobile interface.
- Per-account farming after reboot and restoration of previously active profiles, with combined status in the foreground notification.
- Reduced screen polling in energy saver and isolated logs/settings between profiles.
- Sixteen updated English/Ukrainian screenshots, using explicitly fictional demo data.

### Install

Download **NYXOR-Android-2.4.0-preview.apk** under Assets and install it over the previous version without uninstalling. The certificate matches 2.3.1, and migration of existing account data is covered by automated tests. Requires Android 8.0+ and a 64-bit ARM device; x86_64 is included for emulators.

For additional accounts, open **Accounts**, add a profile and connect Twitch in Settings. Each account has its own Start/Stop controls and reboot preference.

### Validation

84 Python tests, 10 Android Java tests and 20 desktop Node tests passed. Five account tests also passed against Python code extracted from the actual APK. Mobile UI checks cover five viewport sizes; APK contents, matching signing certificate and Android lint were verified.

This is a preview APK with the existing debug signature. The new version has not been tested on a physical phone with real parallel farming; extended background operation and battery savings require practical testing. This release's installer assets are for Android; Windows source is also available in the repository.

**[Windows 2.4.2 preview installer](https://github.com/ThunderBoldX/NYXOR/releases/tag/v2.4.2-windows-preview)** is available in its separate Windows release.
