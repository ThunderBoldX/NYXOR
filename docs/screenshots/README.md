# Зображення NYXOR

Ці PNG показують справжній HTML/CSS/JS-інтерфейс Android-застосунку **2.3.1-preview** у вбудованому режимі `?demo=1`. Це не фотографії фізичного телефона: знімки зроблені у Chromium, область перегляду 390 × 1040 CSS-пікселів, масштаб 2×. Системні панелі Android не входять у кадр. Для картки Rust у демонстраційний стан додано обкладинку категорії з Twitch CDN.

| Український інтерфейс | Англійський інтерфейс | Екран |
| :--- | :--- | :--- |
| `overview.png` | `en/overview.png` | Головний екран: активний стрім, баланс, дві кампанії Drops |
| `points.png` | `en/points.png` | Ігри для поїнтів і перегляд каналів за кількістю глядачів |
| `history.png` | `en/history.png` | Вибір кількох каналів в історії та нараховані поїнти |
| `activity.png` | `en/activity.png` | Отримані дропи з фільтром за грою |
| `settings.png` | `en/settings.png` | Увімкнений режим енергозбереження |
| `rewards.png` | `en/rewards.png` | Каталог нагород; головний екран прокручено вниз |

Усі канали, нагороди, баланси та прогрес — демонстраційні. Знімки не містять реальної сесії Twitch і не підтверджують фактичне нарахування винагород.

Для нових знімків запусти локальний статичний сервер у `android/app/src/main/assets/frontend` і відкрий `index.html?demo=1`. Режим показує інтерфейс без підключення до Twitch. Залишай позначку демонстрації та не використовуй реальні коди авторизації у публічних матеріалах.

Банер `../assets/nyxor-banner.svg` — векторна графіка з місячним знаком застосунку. Він не залежить від зовнішніх шрифтів чи зображень.

Основний `README.md` використовує англійські знімки з `en/`. Український `README_UK.md` використовує початкові знімки з цієї папки. Англійські зображення отримано перемиканням мови в налаштуваннях справжнього інтерфейсу, без заміни тексту на зображеннях.

Для відтворення всіх 12 знімків установи Playwright для Node.js і запусти `node tools/capture_screenshots.cjs` з кореня репозиторію. За потреби вкажи шлях до Chromium у `BROWSER_EXECUTABLE`. Скрипт використовує лише демонстраційні дані, перевіряє центрування місяця на трьох ширинах екрана й завантажує обкладинку Rust із Twitch CDN.
