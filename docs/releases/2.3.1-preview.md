NYXOR 2.3.1 preview for Android brings updated artwork, history controls and optional energy saving.

### New and improved

- Smooth crescent logo across the README banner, app header and launcher icon.
- Properly centered moon in the round Settings shortcut.
- Twitch category artwork on the active-stream card.
- Hold a watched channel to select and remove multiple history entries. Your Streamers list is preserved.
- Each confirmed Drop is saved separately. Activity keeps the latest 500 rewards and supports filtering by game.
- An Energy saver toggle reduces checks, UI updates and animations. Android may pause background farming in this mode; leave it off for the most consistent farming.
- Twelve refreshed screenshots across the English and Ukrainian READMEs.

### Install

Download **NYXOR-Android-2.3.1-preview.apk** below and install it over the existing app. The signing certificate is unchanged. Android 8.0+ and a 64-bit ARM device are required; x86_64 is included for emulators.

### Validation

59 Python tests, 8 Android tests, APK build and Android lint passed. Browser checks cover the new controls and moon alignment at 320, 390 and 768 pixels. Live Twitch farming and battery savings still need testing on physical phones.

This release contains Android only.
