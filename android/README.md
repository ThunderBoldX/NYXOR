# NYXOR Android · 2.2 preview

Android-застосунок для Twitch Drops і Channel Points. Інтерфейс та ядро фарму вбудовані в один APK.

## Установлення

1. Перенеси `NYXOR-Android-preview.apk` у папку завантажень телефона й відкрий файл.
2. Якщо Android попросить, дозволь встановлення з цього джерела для файлового менеджера або браузера, з якого відкрито APK.
3. Відкрий NYXOR → **Налаштування → Підключити Twitch**.
4. Натисни **Скопіювати код**, потім **Відкрити Twitch**. Увійди у свій акаунт і підтвердь код; якщо він не підставився, встав його вручну. Повернися у NYXOR. Або відкрий `https://www.twitch.tv/activate` на ПК та введи той самий код. Пароль вводиться лише на сайті Twitch.
5. У вкладці **Ігри** знайди потрібну категорію та натисни результат пошуку. Або додай Twitch-логін у вкладці **Стрімери** для фарму балів.
6. На головній сторінці натисни **Запустити**. Дозволь повідомлення, щоб бачити стан фарму та кнопку **Stop** у шторці Android.

Зміни списків і параметрів поїнтів застосовуються під час наступної перевірки без перезапуску; зміна списку перериває очікування між перевірками. Закриття екрана не зупиняє фонову службу; для завершення натисни **Зупинити** у застосунку або **Stop** у повідомленні.

Ця збірка підтримує **Android 8.0+ на 64-бітних ARM-пристроях**, а також x86_64 для тестового середовища.

## Якщо Twitch не підключається

Версія 2.0.2 перевіряє підключення перед запитом коду та показує, коли Android не бачить мережі. Після ввімкнення Wi-Fi або мобільних даних натисни підключення ще раз.

Версія 2.0.1 додає резервне визначення адрес через Android та повторну спробу при збої DNS. Встанови новий APK поверх попереднього, без видалення застосунку: за однакового ключа підпису дані збережуться.

При помилці натисни **Перевірити з’єднання**. Перевірка звертається до Twitch без токена і перевіряє доступність API. Якщо адреса досі недоступна, перевір Twitch у браузері, перемкни Wi-Fi / мобільний інтернет і перевір обмеження мобільних даних для NYXOR, VPN та приватний DNS. APK не може усунути відсутність інтернету або блокування у мережі.

## Автозапуск і фонова робота

У **Налаштування → Робота у фоні** ввімкни **Автозапуск після перезавантаження**. Початково він вимкнений. Після ввімкнення телефона та першого розблокування NYXOR спробує запустити фарм зі збереженою чергою. Якщо інтернет ще недоступний, чекатиме підключення. Для запуску потрібні збережений вхід Twitch та ігри або стрімери.

Служба працює після закриття вікна з нещодавніх застосунків і запитує відновлення після завершення процесу через нестачу пам’яті. Кнопка **Зупинити** скасовує відновлення поточної сесії, але не вимикає окремий перемикач автозапуску на наступне перезавантаження.

Натисни **Налаштування батареї застосунку** й обери для NYXOR режим **Без обмежень**, якщо він доступний. Додай застосунок до винятків очищувача пам’яті. Очищення лише кешу не видаляє акаунт; **Очищення даних** видаляє всі налаштування. Після **Примусово зупинити** або аналогічної дії очищувача відкрий NYXOR вручну. Система та виробник телефона можуть затримувати автозапуск.

Повідомлення показує гру, стрімера, прогрес до трьох дропів, очікування мережі або відновлення з’єднання. Оновлюється кожні 15 секунд і після ввімкнення екрана. Щоб бачити його на заблокованому телефоні, дозволь повідомлення NYXOR і показ їхнього вмісту на екрані блокування в Android.

## Поїнти, історія та нагороди

У вкладці **Поїнти → Ігри для поїнтів** додай ігри, за якими дозволено обирати будь-якого онлайн-стрімера з доступними Channel Points. Це окремий список від ігор для Drops. Пріоритет: доступні Drops → явно задані стрімери → ігри для поїнтів. Вимкнений збір поїнтів вимикає обидва варіанти фарму поїнтів.

Вибери **Більше глядачів** або **Менше глядачів** і відкрий **Канали цієї гри**. Популярні канали беруться з першої сторінки Twitch; для менш популярних виконується перегляд сторінок, обмежений 18 секундами та 100 сторінками. Якщо каталог неповний, це зазначено в інтерфейсі. Сортування задає порядок пошуку каналу; працездатний вибір зберігається між скануваннями. Перед фармом повторно перевіряється, чи канал наживо, у потрібній грі та чи доступні поїнти.

**Поїнти → Історія каналів** показує підтверджені перегляди й спостережуваний приріст балансу окремо для кожного Twitch-акаунта. Старий баланс не рахується заробітком. Історія починається після встановлення цього оновлення; витрати або кілька змін балансу між опитуваннями можуть впливати на точність. Попередні заробітки не вигадуються.

На головній під Drops є каталог реальних нагород поточного каналу: ціна, доступність і нестача балів. Для обміну натисни **Відкрити канал**. NYXOR не виконує покупки. Після зупинки показується останній збережений стан; оновлення балансу приходять із Twitch під час фарму.

Рейди можуть вести лише до явно заданих стрімерів або ігор зі списку поїнтів. Для Drops канал як і раніше визначається кампаніями вибраної гри. Повністю вимкнути рейди можна в налаштуваннях.

## Що всередині

- Графічний інтерфейс у вбудованому Android WebView: округлі картки, плавні переходи, шкали прогресу, напівпрозора нижня навігація, тактильний відгук.
- Локальні HTML/CSS/JS-ресурси включено в APK. Для екранів не потрібен зовнішній сайт; WebView не відкриває сторонні сторінки з доступом до внутрішнього мосту.
- Python 3.12 через Chaquopy, наявне ядро NYXOR і виправлений вибір стрімера для кількох кампаній.
- Одна асинхронна петля для майнера, входу й команд. Повторний старт не створює другий майнер; зупинка скасовує активне завдання.
- Служба Android foreground service та wake lock під час фарму. Служба запитує відновлення після системного завершення процесу. Автозапуск після перезавантаження вмикається окремо в налаштуваннях.
- Авторизація, черга, налаштування та історія зберігаються в приватній папці застосунку. Резервне копіювання Android для цих даних вимкнено.
- Українська й англійська мови. Вхід у Twitch підтверджується у системному браузері.

## Стан перевірки

Це **тестова APK-збірка з debug-підписом**, а не реліз у Google Play. Збірка, вміст APK, локальні тести ядра та взаємодія з інтерфейсом перевірені. Ілюстрації інтерфейсу використовують явно позначені демонстраційні дані.

Користувач підтвердив запуск Android-застосунку й успішний вхід після введення коду на ПК. Початкова помилка DNS виникла через вимкнені Wi-Fi та мобільні дані. Причина невдалого підтвердження у браузері телефона ще невідома. Нові перевірки підключення, копіювання коду на фізичному телефоні, нарахування винагород і тривала робота з вимкненим екраном ще потребують перевірки. Поведінка фонової роботи залежатиме також від налаштувань енергозбереження телефона. Збірку й локальні тести перевірено; фактичне перезавантаження, очищувач виробника та вигляд повідомлення на фізичному телефоні потребують перевірки. Немає гарантії безперервного фарму за всіх системних обмежень.

## Збірка з вихідного коду

Потрібні JDK 17, Android SDK 35 / Build Tools 35, Python 3.12 та Gradle 8.11.1. Установи `ANDROID_HOME` на свій SDK; за потреби `NYXOR_BUILD_PYTHON` — на виконуваний файл Python 3.12. Усі інші бібліотеки завантажує Gradle.

```sh
cd android
./gradlew :app:assembleDebug
```

На Windows — `gradlew.bat :app:assembleDebug`. Результат: `app/build/outputs/apk/debug/app-debug.apk`.

Модулі Python копіюються з `core/`, локалізації — з `core/nyxor/locales/`. Код майнера не дублюється вручну. Для оновлень встановленого застосунку використовуй той самий ключ підпису; перед публічним релізом налаштуй власний release signing і збережи ключ окремо від репозиторію.

Для автономного перегляду лише дизайну можна відкрити `app/src/main/assets/frontend/index.html?demo=1` через локальний статичний сервер. Цей режим не підключається до Twitch і не запускає майнер.
